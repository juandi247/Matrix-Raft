Choose a seed and how you want to see the nodes. Read the notes below before you start.

Real Raft
The simulation runs Raft completely inside the engine. It is the same Raft that runs on the deployed nodes, which run the algorithm by sending messages over the network.
Deterministic
Time is a tick counter, and the network and the crashes are simulated. The same seed always produces the same run.
Replayable
If you find a bug or an interesting sequence of events, run it again with the same seed to reproduce it exactly.
